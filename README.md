# Vírgula · memoria sonora viva

Grabadora de campo gratuita para el teléfono: graba en un toque, documenta cada sonido con su ficha y exporta audios y fichas para archivos, bases de datos e investigaciones.

> En los códices mesoamericanos, la **vírgula** es la voluta que sale de la boca de alguien para indicar que habla. Todo sonido viene de alguien.

**Estado:** etapa 0, prueba técnica. Esta versión solo sirve para comprobar que la grabación funciona bien en teléfonos Android.

## Probarla
1. Abre la página desde GitHub Pages en Chrome (Android).
2. Permite el micrófono. Si aparece **⬇️ Instalar** (o ⋮ → *Instalar app*), instálala.
3. Haz las pruebas y comparte el **📋 Informe**.

Todo queda en el teléfono: la página no envía nada a ningún lado.

## Archivos
| Archivo | Qué es |
|---|---|
| `index.html` | La app |
| `manifest.webmanifest` | Nombre, íconos y colores para instalarla |
| `sw.js` | Guarda la app en el teléfono para abrir sin internet (cambia `VERSION` al publicar cambios) |
| `icono-*.png`, `apple-touch-icon.png` | Íconos provisionales |
